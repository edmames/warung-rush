Warung Rush is a fast-paced Indonesian street-food cooking game. Take orders, cook at four stations (wok, grill, cutting board, drink rack), assemble dishes on plates, and serve customers before their patience runs out. A 3-minute shift with escalating rush hours, combos, and quick-service bonuses — all in plain HTML5 Canvas, no network needed.

## Run it

```sh
npx -y tsx serve.ts
```

Then open http://127.0.0.1:4173/ in a desktop browser. Mouse or keyboard (1-4 for stations, Space for quick action, Enter to start, M to mute).
